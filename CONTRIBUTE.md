# Contributing to TypeWriter

Thank you for your interest in contributing! To maintain code quality and security under our MIT license, we have a
strict workflow enforced by GitHub Rulesets.

## 1. Pull Request Workflow

1. **Fork** the repository to your own account.
2. Create a **feature branch** in your fork.
3. Submit a **Pull Request (PR)** to our repository.
4. **Force pushing** is strictly blocked, so please use additional commits to address feedback rather than rebasing
   history.

## 2. The Review Process

* **Approvals:** Every PR requires at least **1 approval** from a maintainer before it can be merged.
* **Stale Reviews:** If you push new code after receiving an approval, that approval will be automatically dismissed,
  and a new review will be required.
